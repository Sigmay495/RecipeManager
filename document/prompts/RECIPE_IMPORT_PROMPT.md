# レシピ一括登録用 ChatGPTプロンプト

## 使い方

1. この文書の「プロンプト本文」をChatGPTへ貼り付ける。
2. `<登録したいレシピ>`へ、料理名、参考URL、参考情報などを記入する。
3. 生成されたJSONをUTF-8の`.json`ファイルとして保存する。
4. 共有Android端末へGoogle Driveなどで渡し、レシピ管理アプリからImportする。
5. Import画面で内容を確認・修正してから登録する。

生成内容は必ず人が確認してください。参照先を確認できない場合、ChatGPTに分量などを推測させず、警告へ記載させます。

## プロンプト本文

```text
あなたは、家庭用レシピ管理アプリへ登録するJSONファイルの作成者です。
以下の入力を、指定されたJSON形式へ変換してください。

【重要なルール】
- 出力はJSONだけにしてください。Markdownのコードフェンスや説明文は付けないでください。
- schemaVersionは"1.0"、fileTypeは"recipe-import"にしてください。
- recipesは1件以上100件以下にしてください。
- 各レシピの分量は必ず2人分へ換算してください。
- 料理名、材料、分量、単位、カテゴリ、調理時間、手間レベル、参照元URLを可能な範囲で整理してください。
- 作り方の本文は含めないでください。参照元URLだけをsourceUrlへ入れてください。
- 確認できない情報を推測で断定しないでください。
- 分量が確認できない材料はamountをnullにし、noteへ「要確認」と記載してください。
- 手間レベルを判断できない場合は"normal"にしてください。
- URLがない場合はsourceUrlをnullにしてください。
- カテゴリは次のいずれかだけを使用してください。
  - one_dish: 丼、麺、カレーなどの一品もの
  - main: 主菜
  - side: 副菜
  - soup: 汁物
- 手間レベルは次のいずれかだけを使用してください。
  - easy: 簡単
  - normal: 普通
  - hard: 手間
- amountは正の数値またはnullにしてください。1/2は0.5へ変換してください。
- 「少々」「適量」など数値化できない表現はamountをnull、unitを"適量"などの表現にしてください。
- JSONにID、最終調理日、削除状態、栄養評価を含めないでください。
- 情報不足や確認が必要な事項は、各レシピのwarnings配列に短く記載してください。

【出力形式】
{
  "schemaVersion": "1.0",
  "fileType": "recipe-import",
  "generatedAt": "ISO 8601形式の現在日時またはnull",
  "recipes": [
    {
      "name": "料理名",
      "category": "one_dish | main | side | soup",
      "ingredients": [
        {
          "name": "材料名",
          "amount": 1,
          "unit": "個",
          "note": "補足。なければ空文字"
        }
      ],
      "cookingTimeMinutes": 30,
      "effortLevel": "normal",
      "sourceUrl": "https://example.com/recipe または null",
      "memo": "任意メモ。なければ空文字",
      "warnings": []
    }
  ]
}

【登録したいレシピ】
<ここに料理名、参考URL、参考情報などを記入>
```

## 出力後の確認項目

- 2人分になっているか
- 材料が抜けていないか
- 数量と単位が分離されているか
- カテゴリが正しいか
- 調理時間と手間レベルが妥当か
- 参照元URLが正しいか
- `warnings`に確認事項が残っていないか
