家族2人向けのAndroidレシピ・献立管理アプリです。現在のバージョンはv1.00です。

バージョンごとの変更内容は[変更履歴](CHANGELOG.md)を参照してください。

## 現在の実装状況

コーディング工程の第9段階まで実装・検証済みです。レシピ、Import、献立の自動提案・評価、履歴、買い物材料リスト、全ユーザーデータのJSONバックアップと復元に対応しています。Android 8.0（API 26）とAndroid 16で総合テストを行い、単体テスト18件、端末テスト15件、Lint、オフライン起動、データを保持したAPK更新を確認済みです。詳細は[総合テスト報告書](document/TEST_REPORT.md)を参照してください。

## 動作環境

- Android 8.0（API 26）以降
- サーバーや常時接続のインターネット環境は不要
- データはインストールしたAndroid端末内に保存

## Android端末への導入手順

現在、GitHub上でインストール用APKは配布していない。リポジトリからビルドする場合は、後述の開発用ビルドで`recipe-manager-debug.apk`を生成する。Debug APKは開発・動作確認用途に限り、日常利用向けの公開時は署名済みRelease APKを使用する。

APKを用意した後は、次の手順で導入する。

1. APKをAndroid端末へコピーする。Google Driveなどへ保存し、端末でダウンロードしてもよい。
2. Android端末の「ファイル」アプリなどからAPKを開く。
3. 初回だけ、APKを開いたアプリに対して「不明なアプリのインストール」を許可する。
4. 画面の案内に従ってインストールする。
5. アプリ一覧から「レシピ管理」を起動する。

Androidの設定名は端末によって異なる。インストール後は、安全のため「不明なアプリのインストール」の許可を元へ戻してよい。

### 更新するとき

先にアプリの「その他」→「データ管理」からバックアップを保存する。その後、旧版をアンインストールせず、同じ手順で新しいAPKを開いて上書きインストールする。アンインストールすると端末内データも削除されるため注意する。

## 簡単な使い方

### 1. レシピを登録する

画面下部の「レシピ」から「新規登録」を選び、料理名、カテゴリ、材料、作り方URL、メモ、調理時間、手間レベルを入力して保存する。登録したレシピは編集でき、削除した場合も「削除済み」検索から復元できる。

PCなどで作成したレシピJSONをまとめて登録する場合は、「レシピ」画面のImportからファイルを選択する。Import前に内容と重複候補を確認できる。対応形式は[`recipe-import.schema.json`](document/schemas/recipe-import.schema.json)を参照する。

### 2. 1週間の献立を作る

「献立」から対象週を選び、自動提案を実行する。祝日と「ご飯不要日」は提案対象から除外される。提案後は料理を個別に変更でき、手間、栄養バランス、旬、食材ロスなどの警告を確認してから保存する。

実際に調理した献立は調理済みとして記録する。記録は献立履歴とレシピの最終調理日に反映され、次回以降の提案で同じ料理が短期間に続かないよう考慮される。

### 3. 買い物リストを作る

「買い物」から対象週を選ぶと、保存済み献立の材料をまとめた一覧を生成できる。同じ材料と換算可能な単位は合算される。献立を変更した後は買い物リストを再生成する。

### 4. ご飯不要日を設定する

「その他」→「ご飯不要日」から、平日でも夕食が不要な日を登録する。登録した日は献立の自動提案から除外される。

### 5. バックアップ・復元を行う

「その他」→「データ管理」からバックアップを実行し、保存先としてGoogle Driveや端末内フォルダを選ぶ。バックアップにはレシピ、献立、履歴、買い物リスト、設定などの全ユーザーデータが含まれる。

復元は現在のデータを全件置き換えるため、先に現在データのバックアップを保存してから実行する。別端末へ移す場合は、元端末で作成したバックアップJSONを新しい端末へ渡し、「データ管理」から復元する。

## 開発用ビルド

必要なJDK、Android SDK、`local.properties`などの準備は[開発環境構築手順](document/DEVELOPMENT_SETUP.md)を参照してください。Android SDKの場所を`src/local.properties`の`sdk.dir`へ設定してから実行します。

```powershell
cd src
.\gradlew.bat testDebugUnitTest connectedDebugAndroidTest lintDebug copyDebugApkToDst
```

Debug APKは`dst/recipe-manager-debug.apk`へ出力されます。

署名済みRelease APKの作成と公開については[リリース手順書](document/RELEASE_GUIDE.md)を参照してください。
